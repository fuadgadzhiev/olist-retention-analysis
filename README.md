# Olist Retention Analysis

**Анализ удержания клиентов и Product/Market Fit маркетплейса Olist (Бразилия)**

## О проекте

Комплексный аналитический проект по оценке эффективности бразильского маркетплейса **Olist** (аналог Wildberries / Ozon).

**Цель проекта** — провести глубокий анализ бизнес-метрик, выявить ключевые проблемы удержания клиентов, оценить Product/Market Fit и предложить конкретные рекомендации для роста.

## Задачи проекта

1. **Когортный анализ** monthly retention
2. **Оценка Product/Market Fit (PMF)**
3. **Определение 5 ключевых метрик** для фокуса продукт-менеджера
4. **Приоритизация гипотез** с помощью фреймворка **ICE**
5. **Метрики для A/B-тестирования** выбранной гипотезы
6. **Финальный отчёт** и презентация для продукт-менеджера

## Основные выводы

### 1. Product/Market Fit **НЕ ДОСТИГНУТ**
- Медианный retention 1-го месяца: **0.51%**
- Retention 3-го месяца: **0.27%**
- Падение retention с 1-го по 3-й месяц: **~95%**

### 2. Ключевые проблемы
- Крайне низкая повторная покупка
- Высокий процент отмен заказов (625 в месяц)
- Слабая вовлечённость клиентов после первой покупки

**Главный вывод**: маркетплейс плохо удерживает клиентов после первой покупки.
